Entry for the [make.fun competition "Five Seconds to Explain the Glass"](https://make.fun/c/u-po-pu-five-seconds-to-explain-the-glass-934d9949): one sentence, spoken by a cat in the five seconds after it sweeps a glass off the table — no apology, no admission, only the cat's most convincing self-defence.

## The sentence

> The glass had been leaning dangerously toward the edge for hours, so my paw simply conducted a routine gravity inspection — a public service, really.

## How it works

`main.py` writes that single sentence (150 characters, within the 200-character cap) to `/output/entry.txt`, honouring `MAKEFUN_OUTPUT_DIR` when set. No network, no randomness, no arguments — every run produces the exact same bytes.

```sh
python3 main.py
```
